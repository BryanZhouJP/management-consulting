問題解決

複雑な問題を、実行可能な仮説と検証可能な要素に分解する — 6 フレームワーク

Issue Tree

質問を MECE のサブ質問へ分解して本質を見つける
適用 避ける
「売上が落ちた理由はどこか？」→ 収益とコスト、価格と数量、顧客別・製品別で分解
  • 複数の要因が並立している場合に有効
  • MECE の観点で分解する
  • 枝ごとに「何を証明すべきか」を明確化

Hypothesis Tree

「こうなるはず」という仮説を、証拠で殺す
適用
「新規市場に参入する価値があるか？」→ 市場規模、認知、価格、販売性を検証
  • 各分岐に kill test を持たせる
  • 仮説と事実を分ける
  • 重要な仮説を優先順位で扱う

Pyramid Principle

結論を先に置き、理由を上に積み上げる
適用
「この投資を進めるべき理由は3つだ」→ 結論→理由→根拠の順で伝える
  • 意思決定の伝達に強い
  • 結論が曖昧だと説得力が落ちる
  • 経営会議の提案書に向く

SCQA

状況・課題・質問・回答で話を整理する
適用
市場が変化しているが、なぜ今投資すべきか？→ 説明の流れを意識する
  • ストーリー性のある分析に向く
  • 聞き手の理解を促しやすい
  • 提案書やプレゼンに有効

MECE

重なりなく、漏れなく分解する
適用
売上の低下要因→ 需要、価格、構造、地域等に分解
  • 問題を正しく分割するための基本
  • 重複や抜けを防ぐ
  • 分析の土台となる

7-Step Problem Solving

問題解決を一連の実務プロセスとして進める
適用
課題定義→分解→優先順位→仮説→分析→提言→実行
  • 分析の流れを固定したいときに有効
  • 作業の迷いを減らす
  • 複雑な業務改善に向く

戦略

業界構造、競争優位、戦略の位置づけを見極める — 11 フレームワーク

Five Forces

業界の構造と収益性を評価する
適用
「この市場に参入して儲かるか？」→ 競争、買い手、供給者、代替品、新規参入を見直す
  • 業界の魅力度を確認
  • 構造的な利益の源泉をつかむ
  • 参入・撤退判断に使う

Value Chain

価値創出とコストの発生場所を明確にする
適用
「どこでコストが膨らんでいるか？」→ 物流、開発、販売、サポートを見える化
  • コスト削減の優先順位を決める
  • アウトソーシングの判断材料になる
  • 業務設計に使える

7S

戦略と組織の整合性を見直す
適用
「なぜ変革が進まないのか？」→ 戦略・構造・システム・文化・人材・スキル・スタイルを確認
  • 組織診断に向く
  • 変革前の整合性確認
  • 問題の切り分けに便利

VRIO

資産が持続的な優位性を持つか見極める
適用
「自社の技術は競争優位か？」→ Valuable, Rare, Inimitable, Organized
  • 戦略的資産の棚卸し
  • 競争優位の本質を見抜く
  • 投資判断の軸になる

3 Horizons

現行事業と新規事業の投資配分を整理する
適用
「今の事業に資源を注ぎすぎていないか？」→ H1 / H2 / H3 を比較
  • 事業ポートフォリオを見る
  • 成長投資と収益維持のバランス
  • 長期成長戦略の設計

Ansoff Matrix

市場と製品の観点から成長戦略を設計する
適用
「新規顧客か既存顧客に対して何を売るか？」→ 市場浸透・開発・多角化
  • 成長の方向性を整理
  • 投資先を比較
  • 市場戦略の選択肢を出す

Growth-Share Matrix

事業ポートフォリオの位置づけを見る
適用
「どの事業に投資すべきか？」→ Star / Cash Cow / Dog / Question Mark
  • 投資の優先順位を整理
  • 事業の成熟度を見える化
  • ポートフォリオ戦略に有効

Nine-Box

市場魅力度と事業強さをマトリクスで比較する
適用
「どの事業を育て、どれを縮小するか？」→ 2x2 の観点で比較
  • 戦略の優先順位づけ
  • 経営会議資料に向く
  • 事業構成を整理する

Blue Ocean

競争のない領域を作る
適用
「競争しない市場を作りたい」→ 既存の競争軸を再設計
  • 市場の新規開拓に有効
  • 競争圧力を回避する打ち手を探す
  • 差別化を設計する

Wardley Mapping

価値創出の進化段階と競争構造を見える化する
適用
「どこを自社で作るか、外部委託するか？」→ Genesis / Custom / Product / Commodity
  • ビルド／買う／外注の判断に役立つ
  • 進化の段階を可視化
  • 戦略の変化を把握

Scenario Planning

複数の将来像に耐える戦略をつくる
適用
「将来の市場変化に耐えられるか？」→ 高い/低いシナリオを前提に検討
  • 不確実性が高い時に有効
  • ロバスト戦略に役立つ
  • 将来リスクを見越す

財務

規模感、収益構造、投資判断の前提を定量的に定義する — 5 フレームワーク

Profit Tree

収益とコストの構造を分解する
適用
利益が落ちているなら、価格、数量、固定費、変動費のどこが要因かを分解
  • 粗利と利益の構造を明確化
  • 改善ポイントの優先順位付け
  • 経営戦略に使いやすい

Revenue Tree

売上の源泉を構造的に見える化する
適用
売上=セグメント × 商品 × チャネル × 価格の組み合わせで分解
  • 問題の主因が売上のどこにあるか判断
  • 事業ビューの整理に有効
  • 戦略の優先順位づけ

TAM / SAM / SOM

市場規模の段階を定義する
適用
「どの程度の市場があり、事業として取りうるか？」→ 全体・対象・獲得可能市場を分けて見積る
  • 投資判断に必要な前提整理
  • 事業の大きさを定量化
  • 成長余地の議論に使う

Unit Economics

顧客1件ごとの経済性を見積もる
適用
LTV, CAC, payback, contribution margin を算出して事業を評価
  • 投資回収の妥当性を測る
  • 成長戦略の持続性を見極める
  • 経営判断に重要

Waterfall / Bridge

売上や利益の変化要因を順に分解する
適用
利益が変わった理由を価格・数量・構造の変化で切り分けて説明
  • 経営会議向けに強い
  • 変化要因を因果的に示せる
  • 改善策の説明に使える

意思決定

選択肢の比較、責任分担、失敗条件の逆算 — 5 フレームワーク

RAPID

意思決定責任を明確にする
適用
「誰が決めて、誰が実行し、誰が承認するか？」を整理
  • 責任の曖昧さを減らす
  • 複数部門横断の意思決定に向く
  • 実行のスピードを上げる

Decision Matrix

重み付けで候補を比較する
適用
「新規参入 / 提携 / 内製」の比較に使う
  • 比較軸を明確にする
  • 感情に左右されにくい
  • 意思決定の説得力を増す

Pre-Mortem

失敗を前提にして逆算する
適用
「この投資が失敗した時、どこで事故るか？」を想定
  • 想定外のリスクに備える
  • 意思決定前の検討を増やす
  • 現場の懸念を吸い出す

Second-Order Thinking

一段先の結果まで考える
適用
「値上げしたら売り上げは増えるか？」→ 次の効果や風土への影響まで見る
  • 単純な思いつきを避ける
  • 副作用を見逃しにくい
  • 長期戦略に有効

Inversion

成功の条件ではなく、失敗条件を逆から考える
適用
「どうすれば失敗するか？」を最初に考えて、回避策を作る
  • リスク管理に役立つ
  • 重要な制約を見つけやすい
  • 意思決定前のチェックに有効

運営

組織変革、顧客体験、変化の受容を設計する — 6 フレームワーク

ADKAR

変化を受け入れる過程を見える化する
適用
「変革が進まないのはなぜか？」→ Awareness / Desire / Knowledge / Ability / Reinforcement
  • 変化のハードルがどこにあるかを見る
  • 現場の抵抗を特定する
  • 人材育成に有効

Kotter

変革を実行するための8段階
適用
「なぜ経営施策が現場に浸透しないか？」→ 8段階で整理
  • 変革プロジェクトの進行管理
  • アクションの順番を整える
  • 変化のスピードを上げる

Lewin

Unfreeze → Change → Refreeze
適用
「新しい運営モデルへの移行は順調か？」→ 変化の三段階を確認
  • 変化を正しく受け入れさせる
  • 変革の持続性を見る
  • 組織文化への影響を見極める

Influence Model

関係者にどう影響を与えるかを見極める
適用
「なぜ部門横断の意思決定が進まないのか？」→ 影響のパターンを確認
  • 説得の仕方を改善
  • 利害関係者を整理
  • 合意形成の手助け

Customer Journey

顧客体験の痛みと機会を見える化する
適用
「なぜ顧客が離脱するか？」→ 体験の各タッチポイントを確認
  • UX / CX 改善に向く
  • 接点ごとの弱点を見つける
  • 施策の優先順位を決める

NPS / Loyalty

顧客のロイヤルティと成長度を測る
適用
「顧客満足が上がっているが売上が伸びない？」→ 推奨者・中立・批判者を分析
  • リテンションと成長要因の把握
  • 顧客の感情を定量化
  • 改善効果のモニタリング

イノベーション

顧客が本当に欲しい価値と新しい事業モデルを見極める — 4 フレームワーク

JTBD

顧客が何を成し遂げたいのかを整理する
適用
「この顧客は何を解決したいのか？」→ 仕事を定義する
  • 価値の本質に迫る
  • 製品の方向性を決める
  • 新規事業の着地点を探す

Business Model Canvas

事業モデル全体を9つのブロックで整理する
適用
「現在の事業の価値生成の構造はどうなっているか？」
  • 事業の骨格を把握
  • 新モデルの設計に有効
  • 事業の分解と再統合

Value Proposition Canvas

顧客価値と提供価値をつなぐ
適用
「顧客が求めている価値と自社の提供が合っているか？」
  • 価値提案の再設計
  • ポジショニングを明確にする
  • 製品改善につなげる

Advantage Matrix

差別化の強さと市場規模の関係を見る
適用
「どこで勝つべきか？」→ 特化 / 量産 / ステイタス / 断念を整理
  • 戦略的選択肢を整理
  • 競争の本質を把握
  • 事業戦略に使える

価格戦略

顧客価値と収益性のバランスを取る — 5 フレームワーク

Value-Based Pricing

顧客価値に応じて価格を決める
適用
「顧客にとって本当に価値があるのはどのレベルか？」
  • 価格の上限を見極める
  • 高付加価値に向く
  • 製品の定義づけに有効

Cost-Plus

原価に利益率を上乗せする
適用
「価格は最低限どこまで下げられるか？」→ 原価と適正利益率
  • シンプルで実務的
  • 製造や実運用に役立つ
  • 利益確保のベース

Competitive Pricing

競合との比較で価格を設計する
適用
「競合とどう差をつけるか？」→ 市場価格とポジショニング
  • 競争が激しい市場に有効
  • 価格競争の前提を把握
  • ブランドの位置づけに影響

Dynamic Pricing

需要やタイミングに応じて価格を変える
適用
「需要が高いときには価格を上げられるか？」
  • 変動需要と供給のバランスを取る
  • 収益最大化に有効
  • 需要予測が要求される

Freemium

無料で導入し、上位機能を有料化する
適用
「最初は無料の方が早く広がるか？」→ 体験の拡張と転換
  • 導入障壁を下げる
  • 利用者数の拡大に有効
  • アップセルの設計が重要
