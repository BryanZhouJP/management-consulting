# 証拠基準 日本語版

> このファイルは元の英語版を日本語向けに要約・整理した版です。正本の英語版は [evidence-standards.md](evidence-standards.md) を参照してください。

## 概要
調査や提案で使う主張の種類を Fact / Inference / Assumption / Estimate に分けて扱う基準です。いちばん大事なのは、主張の種類を明示して誤解を防ぐことです。

## 主な原則
- Fact: 実際に観測された事実
- Inference: 事実から導いた解釈
- Assumption: 判断に基づく仮定
- Estimate: 前提とデータから算出した推定
