# 財務・市場規模・投資判断フレームワーク 日本語版

> このファイルは元の英語版を日本語向けに要約・整理した版です。正本の英語版は [frameworks-financial.md](frameworks-financial.md) を参照してください。

## 概要
財務と事業価値の定量分析に使うフレームワークです。規模感、収益構造、投資判断の前提を明確にします。

## 代表テーマ
- TAM / SAM / SOM のような市場規模の計算
- Profit Tree で収益とコストの構造を分解
- Unit Economics で LTV / CAC / payback を評価
- 水平分解で収益の変化要因を見える化
